# 🍔 DeliveryApp

Aplicativo mobile de delivery desenvolvido em Flutter.

---

## 🚀 Sobre o projeto

O DeliveryApp é um aplicativo mobile criado para simular um sistema simples de delivery de comida.

O projeto foi desenvolvido com Flutter para praticar criação de interfaces mobile, componentes visuais e organização de aplicações em Dart.

---

## ✨ Funcionalidades

- 🍕 Listagem de comidas
- 📱 Interface mobile
- ⚡ Navegação rápida
- 🎨 Cards interativos
- 🛵 Simulação de delivery

---

## 🛠 Tecnologias utilizadas

- Flutter
- Dart
- Material Design

---

lib/

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd deliveryapp-flutter
```

Instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo:

```bash
flutter run
```
